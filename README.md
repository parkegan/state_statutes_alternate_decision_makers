# State LST Statute Explorer

Statute text and coding for laws on life-sustaining treatment (LST) decisions for incapacitated patients in the 50 US states and Washington, DC.

**[Open the explorer](https://parkegan.github.io/state_statutes_alternate_decision_makers/statute_explorer_alternate_decision_maker.html)**

## Explorer content

The map has six views:

- Alternate decision-maker authority over LST decisions
- Withdrawal of artificial nutrition and hydration
- Alternate decision-maker authority over patient-initiated orders
- Patient revocation of LST instructions
- Contemporaneous patient wishes and objections
- Patient competence terminology from the quoted statute excerpts

Click a jurisdiction to read the statute excerpts it was coded on, the code summary, and assigned provisions. 
"Look up a provision" outlines every jurisdiction coded for that provision.

Categories within a view are mutually exclusive. A jurisdiction that meets more than one category is shown under the more stringent one. The legend lists overlaps.

## Sources and limitations

Statute text was taken from official state legislative websites.

We do not plan to update this github with statutes enacted after 2026. 
This is research data and not legal advice. 
Please check the current official code for up-to-date text.
